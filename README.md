# Sahrish Yaseen — Personal Portfolio

A responsive personal portfolio website built as part of my **AUREX Full-Stack Engineering Internship — Month 1, Week 3**.

The portfolio presents my profile, technical skills, education, experience, selected projects, and contact information through a clean and responsive web interface.

## Technologies

* HTML5
* CSS3
* CSS Grid
* Flexbox
* CSS Custom Properties
* Responsive Design

## Features

* Responsive portfolio layout
* About Me section
* Technical Skills section
* Education section
* Experience section
* Projects section
* Contact form
* Responsive navigation
* Hover effects and smooth transitions
* Mobile, tablet, and desktop support
* Accessibility-focused HTML structure
